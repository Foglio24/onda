# Changelog (Windows)

## 0.1.0 (2026-11-15)

### Added
- **Seaglass for Windows 11** (Compose Desktop): Classic three-panel shell (library | page | queue), account sign-in through the Seaglass website with library sync, and **automatic updates** like on the Mac — checks GitHub for `windows-vX.Y.Z` releases (never "Latest"), downloads the installer zip, verifies size and SHA-256, stages it and installs on restart or when quitting.
